# PALAK: THE SERIES

A cinematic, streaming-inspired portfolio for **Palak Singh**, B.Tech CSE student and software developer.
Every section is an episode and every project is an Original.

> A personal portfolio with a fictional streaming-platform look. It is not affiliated with Netflix or any other streaming service and uses none of their logos.

## Run it locally

Requires Node.js 18+.

```bash
npm install
npm run dev
```

Production build (deploy `dist/` to Vercel, Netlify or GitHub Pages):

```bash
npm run build
```

## Updating the content

All content lives in `src/data/portfolio.ts`. Replace the resume at `public/assets/Palak_Singh_Resume.pdf` and the portrait files in `src/assets/` (`portrait-420.webp`, `portrait-720.webp`, `portrait-1100.webp`, transparent background).
